# Security Policy

Do not open a public issue containing a vulnerability, private document,
credential, private locator, customer identifier, or workstation detail.

Report security concerns through GitHub's private **security advisory** form for
this repository. Before the first origin export, the operator must confirm that
private vulnerability reporting is enabled. If that channel is unavailable,
stop and contact the repository owner through a previously verified private
channel; do not invent or publish an address in repository content.

Reports should identify the affected version, bounded reproduction steps, and
impact without attaching real customer or pilot data. Receipt of a report does
not authorize provider access, publication, release, deployment, or inspection
of company runtime state.
